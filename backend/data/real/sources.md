# AquaPulse real-source registry

## CPCB
- CPCB Post-Monsoon 2023 drain monitoring: https://cpcb.nic.in/ngrba/Identified_drains_postmonsoon-2023.pdf
- CPCB Pre-Monsoon 2023 drain monitoring: https://cpcb.nic.in/ngrba/Drains-Pre-Monsoon-2023.pdf
- CPCB Post-Monsoon 2022 drain monitoring: https://cpcb.nic.in/ngrba/Identified_drains_postmonsoon-2022.pdf

The CSV in this folder reproduces only the Dehradun Rispana/Bindal rows used by the prototype, with source/year/season preserved.

## NASA GPM IMERG
- https://gpm.nasa.gov/data/imerg
- https://gpm.nasa.gov/data/directory

IMERG is the planned rainfall ingestion source. For the prototype, high-frequency rainfall remains simulated until an authenticated/downloadable ingestion path is configured.
