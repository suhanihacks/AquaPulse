# AquaPulse Architecture — Final Build

## Frontend
React + Vite + React Leaflet provides the Command Center, River Memory, Hot Moments, Verification Centre and Evidence views.

## Backend
FastAPI exposes the data, intelligence, citizen-observation and verification APIs.

## Intelligence
The backend combines event fusion, event fingerprinting, River Memory similarity, hot-moment scoring, graph-based downstream prioritization and verification ranking.

## Data boundary
Official/contextual evidence is separated from derived values and simulated demo signals. The final prototype never silently upgrades simulated data into live telemetry.

## Human-in-the-loop
The system ranks investigation priorities. A human verifier confirms or rejects the event interpretation.
